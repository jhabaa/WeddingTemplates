# 💍 Micheline & Jeroen's Wedding Celebration

A beautiful, modern, and romantic wedding invitation website designed with a sophisticated **Glassmorphism** aesthetic. This project serves as a digital gateway for guests to celebrate the union of Micheline and Jeroen.

## ✨ Features

- 💎 **Glassmorphism UI**: A stunning frosted-glass effect applied to all interactive elements and content containers, providing depth and elegance.
- 🎥 **Cinematic Experience**: An immersive hero section featuring a full-screen video background and a dedicated video modal for the wedding trailer/movie.
- 📱 **Fully Responsive**: Optimized for all devices, from large desktop monitors to mobile phones, ensuring every guest has a seamless experience.
- 💬 **Instant RSVP/Contact**: Integrated WhatsApp functionality allowing guests to reach out with a single click.
- 🎨 **Elegant Typography**: Custom font integration (`Maratre`) combined with modern system fonts for a premium feel.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Advanced styling including `backdrop-filter` for the glass effect, CSS Gradients, and Flexbox/Grid for layout.
- **FontAwesome**: High-quality iconography for interactive elements.
- **JavaScript**: Lightweight DOM manipulation for modal controls and interactivity.

## 🚀 Getting Started

To view this project locally, follow these simple steps:

1.  **Clone the repository** (or download the source files):
    ```bash
    git clone <repository-url>
    cd Micheline
    ```

2.  **Add Assets**: Ensure you have the following assets in your project folder for the full experience:
    - `trailer.mp4` (Hero background video)
    - `fullmovie.mp4` (Video for the modal)
    - `Maratre.otf` (Custom wedding font)

3.  **Launch**: Open `index.html` in any modern web browser (Chrome, Firefox, Edge, or Safari).

